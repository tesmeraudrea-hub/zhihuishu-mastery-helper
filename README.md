# 知到智慧树掌握度满分助手

> **警告：本脚本仅适用于智慧树掌握度练习 用于有答题次数限制的练习后果自负**
>
> **脚本不会自动识别课程是否限制答题次数，请在启动前自行确认。**

作者：Watson · 版本：v1.8.1 · MIT 许可

根据网站实际批改重复练习，记住正确答案、排除错误组合；也可以导入别人分享的 TXT，再用实际作答验证、纠错并补充自己的题库。所有课程分别保存，题库处理在本地进行。

## 两种运行模式

| 模式 | 适合做什么 | 何时停止 |
| --- | --- | --- |
| 满分练习（默认） | 完成课程掌握度，跳过免考与已确认 100% 的知识点 | 全部非免考项满分；也可在运行设置选择当前知识点 |
| 题库完善 | 忽略网站原有满分，实际复练、验证旧答案并收集新题 | 每个非免考知识点答至全对，全部遍历一轮后停止 |

绿色可能只有 80% 或 90%。满分练习读取具体百分比，不会仅凭颜色判断完成；题库完善则依据本轮实际提交与批改判断完成，不把旧满分答卷当作本轮复核结果。

题库完善的轮次按课程保存在本机。暂停、刷新、页面跳转后可以继续，已完成项目本轮不再重复。结束后点击“开始新一轮”，核对提示并确认，才能重新遍历；不会无限自动循环。

一轮结束只代表本轮知识点已完成，不代表收集了网站全部题目。随机抽题可能在后续轮次提供新题；再次进入原有满分练习也可能临时改变网站掌握度，直至重新全对。

## 新面板怎样使用

- **练习页**：当前课程、运行模式、对应进度、开始／暂停。操作间隔、练习范围和匹配方式放在折叠的“运行设置”；日志单独折叠。
- **题库页**：选择课程，查看可分享的确认题数，导入 TXT 或导出 TXT。JSON 记录、未入库清单和清理操作收进“更多数据操作”。
- **右上角 ?**：内置首次使用、导入题库、制作与分享、常见问题。常见问题点击展开；帮助页说明当前模式，点击返回或按 Esc 回到原页面。
- 面板可拖动标题栏，收起后成为可拖动悬浮球；位置与收起状态会保存。收起和切换页签都不等于暂停。

## 安装与更新

安装篡改猴后，从 [最新 Release](https://github.com/tesmeraudrea-hub/zhihuishu-mastery-helper/releases/latest) 下载 `copy-script.html`，用浏览器打开并复制完整代码，在篡改猴中新建脚本、整体粘贴并保存。

开发或发布站同步只使用仓库中的 [zhihuishu-mastery.user.js](zhihuishu-mastery.user.js)，它是唯一的正式源码。

已有旧版时，请在原脚本条目的代码编辑区 Ctrl+A → Ctrl+V → Ctrl+S 整体替换，刷新智慧树后检查标题 v1.8.1。无需先删除原脚本或清除数据。不要把代码追加到旧版末尾。

若没有面板，检查脚本是否启用，以及浏览器是否允许扩展执行用户脚本。本地安装不需要运行 Node 或测试文件。

## 第一次使用

1. 在篡改猴中安装完整脚本，打开智慧树课程的掌握度热力图。
2. 确认练习不限答题次数，关闭其他脚本的自动答题和自动提交功能。
3. 选择“满分练习”，点击“开始 / 继续”。脚本先核实掌握度，再处理未满分知识点。
4. 如果主要想制作题库，选择“题库完善”。已有满分也会进入，每个知识点全对后继续下一项。
5. 遇到页面卡住或异常弹窗时，先暂停，检查页面后再继续。

默认操作间隔 **100 毫秒**，支持 0～10000 毫秒，上下箭头每次调整 50 毫秒。

**操作间隔为选项切换、悬浮弹窗和页面更新提供响应时间，如流畅运行可尝试更低值。**

0 毫秒只取消人工等待，不会取消页面加载、选中状态和批改检查。若出现选择未生效或超时，调高间隔并检查页面。

## 使用别人分享的题库

1. 暂停运行，进入“题库”，选择导入目标课程。
2. 点击“导入 TXT 题库”，选择文件。也支持本脚本导出的 JSON 记录。
3. 核对预览中的课程、识别题数、有效题数、新增、重复和冲突，再点击“确认导入”。格式错误的条目可以导出原因清单。
4. 回到“练习”开始。默认顺序为：已确认答案 → 匹配到的导入候选 → 原有猜题算法。

TXT 支持 UTF-8、带 BOM 的 UTF-16 和常见 GB18030 编码；单文件不超过 20 MB，每课程合并后最多 20000 道导入题。相同题目合并，重复答案去重，互相冲突的答案保留为候选。

导入答案未经网站判对时不会混入可分享的确认题库，也不参与课程多选分布统计。JSON 同样只提取题目与答案作为候选，不恢复其他人的轮次、进度和待提交状态。

| 匹配方式 | 规则 |
| --- | --- |
| 宽松匹配（默认） | 题型一致，忽略标点、空白和字母大小写后题干相似度至少 80%；选项优先按内容对应，模糊对应至少 85%，最佳与次佳相差至少 8 个百分点 |
| 严格匹配 | 题型、规范化题干和全部选项内容一致；选项字母、顺序可以不同 |

两者都要求答案唯一对应到当前选项。图片标记不作模糊匹配，也没有图片文字识别。宽松匹配可能增加误猜次数，最后以实际批改为准。

## 制作和分享题库

1. 可以先导入现成题库，减少重复猜题。
2. 在课程热力图选择“题库完善”，开始复练。旧确认答案若被网站判错会失效，脚本继续尝试；完全相同题目跨知识点的旧记录也会按最新批改修正。
3. 查看本轮统计：新增确认、复核正确、纠正答案、待解决。各项含义见下方说明。
4. 完成后在“题库”页选择对应课程，点击“导出纯文字题库”。只导出判对、内容完整且无冲突的题，重复题合并。
5. 分享 TXT 时建议附上课程名称、学校或授课教师、导出日期及题目数量，不必分享 JSON 运行记录。分享前检查题目和图片链接是否适合公开，并确认有权分享。


本轮统计可以这样理解：

- **新增确认**：之前没有记住这道题的正确答案，这一轮做对了，已存入题库。
- **复核正确**：题库里原来就有正确答案，这一轮再次作答，网站仍然判对。
- **纠正答案**：原来保存或导入的答案被判错，重新尝试后找到了正确答案。
- **待解决**：这一轮已经遇到，但还没有做对的题目。

同一道题反复作答不会重复计数。如果一道新题的导入答案有误，修正后会同时计入“新增确认”和“纠正答案”。

推荐 TXT 格式如下，答案使用选项内容，独占一行；多选用分号分隔，判断题用 true / false：

```text
1.【单选题】哪种图形有三条边？
A.圆形
B.三角形
三角形

2.【多选题】哪些数是偶数？
A.2
B.3
C.4
2;4

3.【判断题】三角形有三条边。
true
```

导出文件使用 UTF-8 并带 BOM，文件名含课程名称、课程 ID、导出时间。图片题可能附带图片网址；不同搜题软件要求不同，可以先用少量题目试导入。


**为什么导出的题目可能比导入的少？**

导入是把文件里的答案存进来供脚本尝试；导出则只分享已经在网站上做对、题目和选项记录完整、没有答案冲突的题目。

例如导入 100 道题，这次遇到并做对了 60 道，另外 40 道还没遇到。那么这批导入题中只有前 60 道可以导出，原来题库中符合条件的其他题目也会一起导出。

还没遇到的题，可以用“题库完善”模式继续练习、验证。已经做过却未导出的题，可在“题库 → 更多数据操作 → 导出未入库清单”查看原因。网站可能随机出题，一轮不一定能遇到所有题。

## 高级测试与多选优先级

题库完善的“运行设置”中可勾选“忽略运行前已有答案”。新一轮将忽略原有确认、错误排除与导入候选，只使用本轮新反馈来试题；原题库不被清空，新批改仍会保存。这用于测试猜题能力，正常制作题库建议关闭。

该设置在一轮开始时固定；暂停后更改选项，只影响下一轮。开始新一轮会重置本轮进度与未处理答卷，保留已有题库和历史答题记录。开发测试可直接使用正式版中的“忽略运行前已有答案”设置。

多选始终覆盖完整非空组合。五选题默认参考已有课程 46 道题的“正确选项个数”分布，折算成 20 道弱参考样本；初始数量优先级为四项、三项、全选、两项、单项。当前课程确认的新样本会逐渐占主导；其他选项数至少积累 12 道有效样本后调整。忽略旧答案的测试只学习本轮分布。优化参考选项个数，不参考 A/B/C 字母或排列位置。

## 数据保存与隐私

脚本读取适配页面上的课程名称、网址中的课程与知识点 ID、掌握度、题干、选项、已选答案和批改结果。脚本不要求输入账号密码，没有读取、保存账号密码或浏览器 Cookie 的功能。

本地记录包括题干、题型、最近的选项内容及图片地址、已确认答案、排除的错误组合、知识点信息、轮数、待批改状态和进度。题库完善还保存本轮开始时间、完成列表、每题复核状态及本轮试题记录。课程分别保存，新一轮保留累计题库。

| 数据 | 保存位置与保留方式 |
| --- | --- |
| 课程题库、设置、面板位置与收起状态 | 当前浏览器的脚本存储；刷新和跳转后保留 |
| 运行恢复状态、掌握度核实缓存 | 同一标签页的会话存储；运行中刷新或跳转可继续，手动暂停后需点击继续 |
| 界面日志 | 当前页面内存；每课程最近 150 条，显示最近 12 条，完整刷新重新开始 |
| 导出文件 | 浏览器下载位置，由用户管理；清除脚本记录不会删除文件 |

导入 TXT／JSON 时通过浏览器在本地读取文件，预览仅在当前页面内存中；确认导入后，候选答案写入所选课程的脚本存储。文件内容不会作为代码执行，也不会上传给开发者。文件名只用于预览，匹配方式作为全局设置保存。导入不会恢复历史轮数、进度或待提交状态，没有跨设备同步或完整运行状态恢复。

当前版本没有开发者后台、远程搜题、自动上传或统计上报。帮助内容随脚本内置。脚本会实际选择答案和提交答卷，智慧树仍会接收正常页面访问和答卷请求；浏览器、扩展和智慧树自身的数据处理需另行查看其说明。

| 操作 | 影响范围 |
| --- | --- |
| 导出纯文字题库 | 所选课程已确认、完整且无冲突的题目 |
| 导出记录 JSON | 所选课程的题库、导入候选、完善轮次和当前页面近期日志，供本地检查 |
| 导出未入库清单 | 所选课程未确认、不完整或冲突的已收集题目及原因 |
| 清除导入题库 | 所选课程的导入候选，保留确认答案与尝试记录 |
| 清除当前课程记录 | 当前浏览课程的本地答案、尝试记录、导入候选和完善轮次 |

清理不修改网站成绩，也不删除其他课程、全局设置、面板位置、当前页面已有日志或已下载文件。在原脚本条目内整体更新代码继续使用已有存储；卸载脚本或清除扩展存储可能丢失数据，请先导出需要的内容。浏览器或扩展自身的备份、同步需单独管理。

导出在本地生成文件，不会发给开发者。JSON 可能含课程名称、课程 ID、知识点及题目内容，TXT 包含题目、选项和确认答案，分享前请检查内容。公开反馈时遮住个人信息，不要提供密码、Cookie 或完整登录链接。

## 适用范围与常见问题

适配 `https://studywisdomh5.zhihuishu.com/` 下的掌握度热力图、知识点练习、结果页和解析页，支持单选、多选、判断，每题 1～12 个选项。未适配作业、正式考试、视频学习和其他站点。

| 问题 | 说明 |
| --- | --- |
| 已满分仍练习 | 题库完善的正常行为；满分练习也不会跳过低于 100% 的绿色项 |
| 一轮结束是否收齐全部题目 | 不保证。网站可能随机抽题，可以开始新一轮继续收集 |
| 导入多、导出少 | 导入的答案需先在网站上做对才能分享；还没遇到的题暂不导出。已做过但未导出的题可查看未入库清单 |
| 已判错组合还会一直尝试吗 | 同一题已判错组合会排除，旧确认被判错后也会撤销 |
| 等待热力图载入很久 | 不会重复发起跳转；可刷新续跑，或暂停后检查页面再继续 |
| 没有面板或重复声明报错 | 检查扩展权限和脚本是否启用；在原代码编辑区整体替换，勿把新代码追加到旧代码后 |
| 题目异常、卡住、未知弹窗 | 暂停并手动检查，必要时调高间隔；不要让多个自动答题脚本同时运行 |

脚本是独立第三方工具，请确认课程允许这种练习方式。

本地模拟和代码测试不能替代所有课程、浏览器与网站页面版本的验证。遇到问题可提供版本、浏览器、页面类型和最后提示，公开截图前遮住个人信息，无需发送账号密码。
