# 知到智慧树掌握度满分助手

> **警告：本脚本仅适用于智慧树掌握度练习 用于有答题次数限制的练习后果自负**
>
> **脚本不会自动识别课程是否限制答题次数，请在启动前自行确认。**

当前版本：**v1.7.0** · 作者：**Watson** · 许可：**MIT**

用于智慧树电脑端的掌握度热力图与知识点练习。脚本根据网站的逐题批改结果排除错误答案，复用已确认答案，继续练习至当前答卷全部正确，再返回热力图处理下一知识点。

**只有核实为 100% 的知识点才算完成。绿色也可能是 80% 或 90%，不会仅凭绿色跳过。**

## 适用范围

- 适配网址： https://studywisdomh5.zhihuishu.com/ 下的掌握度热力图、知识点练习、结果页和解析页。
- 支持单选题、多选题和判断题，每题 1～12 个选项。
- 依赖可以重复作答、并显示逐题正确或错误反馈的练习。它会实际选择选项并提交答卷。
- 当前版本只适配上述练习流程。作业、正式考试、视频学习和其他站点没有实现适配。
- 已有电脑端 Edge 的使用反馈与本地模拟回归验证。其他浏览器、移动端和不同页面版本未逐一验证。

脚本是独立的第三方工具，不代表智慧树官方。使用前请确认所在课程允许这种练习方式。

## 安装

1. 从 [篡改猴官网](https://www.tampermonkey.net/) 选择与你的浏览器对应的扩展并安装。
2. 解压本发布包，打开“完整脚本复制页面.html”，点击“复制完整脚本”。也可以用文本编辑器打开“知到智慧树掌握度满分助手-完整代码.txt”，复制全部内容。
3. 打开篡改猴管理面板，选择“添加新脚本”。在代码编辑区全选原有示例代码，粘贴完整脚本，再按 Ctrl+S 保存。这是篡改猴支持的 [手动安装方式](https://www.tampermonkey.net/faq.php?q=Q102)。
4. 确认脚本已启用，然后刷新智慧树页面。左下角出现“知到智慧树掌握度满分助手 v1.7.0”即表示脚本已加载。

部分 Chrome / Edge 环境还需要在扩展设置中允许用户脚本执行，具体入口随浏览器版本变化，请按篡改猴的 [执行权限说明](https://www.tampermonkey.net/faq.php?q=Q209) 检查。

本地安装不需要运行 Node.js，也不需要打开项目中的测试文件。

## 第一次使用

1. 登录智慧树，打开课程的“掌握度”热力图。
2. 暂停其他助手的自动答题和自动提交，避免多个工具同时修改同一份答卷。
3. 第一次可以先选“当前知识点：本轮全对后停止”，手动进入一个未满分知识点的练习，再点击“开始 / 继续”，观察选项选择与批改过程。
4. 确认流程正常后，回到热力图，选择“全部知识点：仅跳过免考和100%”，点击“开始 / 继续”。
5. 需要停止时点击“暂停”。右上角的收起按钮将面板变为悬浮球，脚本仍会运行；点击悬浮球重新展开。

## 面板与悬浮球

- 拖动标题栏移动面板；拖动悬浮球移动收起后的入口。拖动不会触发展开，也不会改变答题状态。
- 面板与悬浮球的位置、收起状态会在当前脚本条目中保存，刷新或跳转页面后继续使用。
- 悬浮球显示最近一次核实的满分进度；右下角绿点表示运行中，灰点表示暂停，黄点表示准备中。
- 展开后，满分数量、完成比例和开始 / 暂停按钮优先显示；“题库与记录”“运行记录”点击后展开。
- 拖动与窗口尺寸变化时自动限制在可见范围。小窗口下内容区域可以滚动，开始 / 暂停按钮保留在底部。
- 警告和次数限制说明在展开后的顶部显示；收起后悬浮球提示仍注明只适用于不限次数的掌握度练习。

全部知识点模式启动时，会先逐项打开悬浮弹窗，核实具体掌握度。知识点较多时，这一步需要一些时间，面板会显示正在核实的项目。

## 运行逻辑与进度

蓝色免考项直接跳过；其他项读取悬浮弹窗中的掌握度，仅 100% 跳过。80%、90% 和 99.9% 都会继续练习；无法识别百分比时暂停。

单选和判断逐项尝试，多选尝试完整的非空组合。已判错的组合不再尝试，已判对的答案按选项内容复用，所以选项字母或顺序变化不影响复用。多选优先级会参考本课程已确认答案中“正确选项个数”的分布，组合仍会完整覆盖；遇到少见答案时可能需要较多轮。

所有课程使用同一套学习规则，不绑定任何固定课程 ID。五选题以原课程 46 道已确认答案的数量分布作为默认参考：两项 1 道、三项 28 道、四项 16 道、五项 1 道，折算为 20 道样本。初始顺序为“四项 → 三项 → 全选 → 两项 → 单项”，只参考选项个数，不参考字母或选项位置。

当前课程每新增一道去重后的有效正确多选题，就叠加一个样本并重新排序，不需要等到 12 道才影响五选题优先级。原课程参考的权重固定为 20，当前课程积累 N 道五选题后，自身权重占 N/(20+N)，因此会逐渐适应该课程。其他选项数缺少可靠默认统计，仍从完整枚举顺序开始，至少积累 12 道该选项数的有效正确多选题后调整排序。默认参考只用于排序，不是预置题库，也不计入已解题数和题库导出；删除本课程记录会清除课程样本，并回到默认顺序。

当前答卷全部正确后，脚本保存批改结果，通过当前课程网址直接返回热力图。4/5 不算完成，会继续重答。全部知识点模式继续下一项，当前知识点模式返回后停止。

面板只显示满分进度：

    满分进度：已确认100% 12/20（60%）
    免考 5 · 剩余 8 · 尚待核实 3

这里的分母是可练习知识点数量，不包含免考项。“尚待核实”不计为满分，也包含在剩余数量中。答题页显示最近一次热力图的核实结果。

## 操作间隔

默认 **250 毫秒**，可设为 0～10000 毫秒，上下箭头每次调整 50 毫秒，也可以直接输入数值。

**操作间隔为选项切换、悬浮弹窗和页面更新提供响应时间，如流畅运行可尝试更低值。**

0 毫秒表示取消这一项人工等待，页面加载、选中状态核对和批改等待仍然保留。实际速度还取决于网站响应与题目组合数量。若调低后出现选择未生效或超时，调高间隔再继续。

有效设置会立即保存；空白、负数和非法输入在结束编辑时恢复为之前的有效值。升级时保留已有设置，默认 250 毫秒只用于尚未保存设置的用户。

## TXT 题库导入

展开“题库与记录”，选择“导入 / 导出课程”，再点击“导入 TXT 题库”。TXT 是主要格式，也可以选择本脚本导出的 JSON 记录。导入前请暂停运行，确认没有其他标签页正在运行目标课程。

1. 选择题库文件。支持 UTF-8（含 BOM）、带 BOM 的 UTF-16 和常见 GB18030 编码；单个文件不超过 20 MB，每课程合并后不超过 20000 道导入题。
2. 核对预览中的目标课程、识别题数、可用题数、新增答案、重复答案和冲突数量。预览会列出前 3 道可用题目；无法识别的条目可导出原因清单。
3. 点击“确认导入”。相同题干、题型与选项的题目合并，相同答案去重，冲突答案保留为多个候选。
4. 点击“开始 / 继续”。顺序为：本地已确认答案 → 能匹配的导入候选 → 原来的猜题算法。导入候选被判错后排除该组合，继续尝试其他候选或猜题。

导入内容保存在所选课程的独立候选题库中，刷新后保留，不覆盖已确认答案。未验证候选不参与多选分布学习，也不写进“导出纯文字题库”；经网站判对后才进入正式答题记录。JSON 导入同样只提取题目和确认答案作为候选，不恢复历史轮数、进度或待提交状态。

### 匹配方式可选

| 模式 | 规则 |
| --- | --- |
| 宽松匹配（默认） | 忽略标点、空白和字母大小写后，题干相似度至少 80%。先按选项内容对应；对应不上时允许至少 85% 的选项文字相似度，并要求最佳项与次佳项相差至少 8 个百分点 |
| 严格匹配 | 题型、规范化后的题干和全部选项内容一致；题号、选项字母和选项顺序可以不同 |

两种模式都要求答案能唯一对应到当前选项，无法对应、映射含糊或题型不同时跳过。宽松模式可能匹配到意思不同的近似题，实际批改会决定是否保留答案。图片不进行文字识别，图片标记不作模糊对应。设置在本脚本条目中保存。

TXT 推荐使用下方“TXT 题库格式”的排布；也支持 `答案：AC`、`正确答案：选项内容`、全角分号及没有选项行的标准判断题。题目以 `1.【单选题】题干` 或 `1.题干` 开始，选项与答案分别占行。没有题型时会根据答案尝试推断；若多选题只有一个正确选项，请明确标注“多选题”。格式不明确的条目会显示为无法识别，其他有效题目仍可导入。

“清除导入题库”只删除所选课程的导入候选，保留已确认答案与尝试记录。“清除当前课程记录”会同时清除当前页面课程的答题记录和导入候选，不修改网站成绩。

独立测试版仍会在每次手动开始时清空测试答题记录，但保留用户主动导入的候选题库；可以先导入再开始。想比较无题库效果时，先清除测试版的导入题库。测试时只启用正式版或测试版中的一个。

## 记录与题库导出

脚本按网址中的课程 ID 分开保存记录。面板显示当前课程名称，将鼠标停在课程名称上可查看包含 ID 的提示。“题库与记录”中的“导出课程”下拉框列出已收集记录的课程。

| 按钮 | 导出内容 |
| --- | --- |
| 导出记录 | 所选课程的题目、已确认答案、已排除组合、轮数、提交状态、进度等 JSON，以及当前页面期间该课程的最近日志 |
| 导出纯文字题库 | 已确认正确、选项数据完整且没有答案冲突的题目，格式为 TXT |
| 导出未入库清单 | 没有写入正式题库的题目及其原因，方便定位未确认答案、数据异常或答案冲突 |

选择导出课程只改变导出目标，不切换正在练习的课程。文件名包含课程名称、课程 ID 和导出时间。

### 数据从什么时候开始保留

答案、已排除组合和课程信息，从本脚本在这个浏览器的当前脚本条目下首次保存它们时开始累计。刷新或直接跳转页面不会清空这些记录，升级时整体替换原条目的代码也会继续使用它们。

界面日志不作长期归档：每个课程仅保留当前页面加载期间的最近 150 条，面板显示最近 12 条。完整刷新会重新开始日志，因此“导出记录”不等于导出自首次运行以来的全部日志。

同一标签页在运行中的页面刷新或跳转可自动继续。手动暂停会取消自动继续；手动再次开始时重新核实掌握度。关闭浏览器后应打开课程、核对状态并手动开始。

本脚本没有实现跨设备同步。支持将 TXT 或 JSON 中的题目答案导入为候选，但不支持完整恢复运行状态。卸载脚本、删除脚本存储、清除扩展数据或使用不同的浏览器配置文件，都可能使原记录无法继续使用。

### TXT 题库格式

以下为排版示例，不是课程题库：

    1.【单选题】下列哪种图形有三条边？
    A.圆形
    B.三角形
    C.正方形
    三角形

    2.【多选题】下列哪些数是偶数？
    A.2
    B.3
    C.4
    2;4

    3.【判断题】三角形有三条边。
    true

选择题逐行列出选项，答案写正确选项的内容；多选答案用半角分号分隔。标准判断答案写 true / false。题目之间空一行，文件使用 UTF-8 编码并带 BOM。

只导出已收集且被网站判对的题目，合并同课程跨知识点的重复题；答案冲突项暂不导出。图片选项可能附带图片网址，脚本不会把图片文字自动识别成正文。不同搜题软件的导入要求不同，可以先用少量题目试导入。

网站显示满分不代表本地一定保存了该知识点所有答案。例如安装脚本前就已经满分的知识点会被跳过，不会凭空加入题库。导出提示中的“未确认”“数据异常”和“答案冲突”指被排除的记录，不代表正式 TXT 中混入了未确认答案。

### 清除记录

先暂停，再点击“清除当前课程记录”并确认。这会清除当前页面课程的本地答案、尝试记录和导入候选题库，不修改网站已有成绩，也不清除其他课程记录。即使“导入 / 导出课程”选了另一个课程，清除当前课程记录的目标仍然是当前页面课程；“清除导入题库”则针对下拉框所选课程。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 没有悬浮窗 | 检查篡改猴和脚本是否启用、域名是否匹配，以及用户脚本执行权限；确认代码已整体替换并保存，再刷新。检查编辑器是否有语法错误 |
| 提示重复声明或 Identifier has already been declared | 在原脚本的代码编辑区全选后整体替换，不要把新代码追加在旧代码后面 |
| 已在热力图却提示未识别或加载超时 | 等待方框与弹窗加载完成，再点击继续；若仍失败，记录版本、页面路径和面板提示并反馈 |
| 绿色知识点仍然进入练习 | 查看具体掌握度。绿色不一定是 100%，低于 100% 继续练习是正常行为 |
| 同课程已有另一个标签页运行 | 暂停其他正在运行的同课程页面，再启动当前页 |
| 验证码、未知弹窗或网站提示出现后暂停 | 手动处理页面提示，确认页面正常后点击继续；脚本不会自动完成验证码 |
| 多选题重答很多轮 | 完整组合数量随选项数增加，尚未确认答案时可能需要多轮；检查网站是否确实允许重复练习 |
| 选项未生效、提交后没有批改结果 | 先观察页面实际状态，调高操作间隔，检查其他脚本是否同时操作。不要在批改尚未返回时反复手动提交 |
| 正确答案与批改不匹配，或所有组合都判错 | 暂停，检查是否打开旧解析、题目是否变化或受其他助手干扰；导出记录与未入库清单后反馈 |
| 题库数量比网页题目数量少 | 跳过的已满分项未必有本地答案，未确认或异常项也不会写入正式 TXT。查看“导出未入库清单” |
| 导出课程名称没有识别 | 打开对应课程的热力图，等待名称识别；识别前仍按课程 ID 区分 |

## 隐私、权限与已知限制

脚本只声明对适配域名的运行匹配。申请的篡改猴权限用于读写本地记录、列出已保存课程，以及添加开始 / 暂停菜单。

v1.7.0 没有实现向开发者或第三方服务器上传记录、远程搜题或统计上报的功能。自动作答会触发学习网站本身的正常请求。浏览器、网站与篡改猴扩展自身的处理方式不由本脚本控制，详见 [数据与隐私说明](PRIVACY.md)。

页面结构变化、图片题、重复且无法区分的选项、网站批改异常或次数限制可能导致无法继续。脚本有暂停检查，但不能保证识别所有异常，也不作不会被平台检测的承诺。开始后请留意首次运行的反馈。

## 更新

在篡改猴中打开原脚本条目，先点击代码编辑区，再按 Ctrl+A → Ctrl+V → Ctrl+S，整体替换并保存。不要先删除原脚本或清除存储；可以先导出需要保留的记录。刷新网站后检查面板版本号。

本地发布包使用手动更新方式，没有配置发布站点的自动更新地址，也没有设置固定的发布主页或反馈地址。后续版本变化见 [更新记录](CHANGELOG.md)。

## 排查问题时可以记录什么

遇到问题时，可以先保存以下信息；如需向脚本分享者求助，也方便说明情况：

- 脚本版本、浏览器版本、篡改猴版本。
- 发生问题的页面：热力图、答题页、结果页或解析页。
- 操作模式、间隔、复现步骤及面板最后的提示。
- 遮住个人信息的截图；有必要时附上相关题目的未入库清单或经过脱敏的记录片段。

无需提供账号、密码、验证码或完整登录信息。截图和网址中的姓名、头像、课程 ID、知识点 ID 等，应在公开反馈前按需要遮挡。
